# Pferdeosteopathie und Reitunterricht – Melanie Siedentop

Website für www.pferdeosteopathie-siedentop.de, ausgeliefert über GitHub Pages.

## Dateien

| Datei | Zweck |
|---|---|
| `index.html` | Startseite mit allen Texten, Preisen und Kontaktdaten |
| `impressum.html`, `datenschutz.html` | Rechtstexte |
| `style.css` | Farben und Gestaltung (Farben ganz oben unter `:root`) |
| `script.js` | Menü, Galerie, Kontaktformular |
| `CNAME` | Verbindet GitHub Pages mit der eigenen Domain (nicht ändern oder löschen) |
| `fonts/` | Schriften, lokal eingebunden |
| `images/` | Fotos, siehe `images/LIESMICH.txt` |
| `ueber-mich/`, `leistungen/` usw. | Weiterleitungen der alten Adressen auf die neue Seite |

## Texte ändern

Die Datei auf GitHub öffnen, auf das Stift-Symbol klicken, Text ändern, unten auf „Commit changes" klicken. Nach ein bis zwei Minuten ist die Änderung online.

## Logo, Flyer und Fotos hinzufügen

Das Logo als `logo.svg` (transparenter Hintergrund) und Fotos (jpg, jpeg, png oder webp) in den Ordner `images/` hochladen, genau wie in `images/LIESMICH.txt` benannt. Die Seite erkennt sie automatisch.
